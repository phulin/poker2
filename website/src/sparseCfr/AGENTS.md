## Directory summary
Sparse public-tree CFR WebGPU runtime and grouped shader modules.

### Source files
- `SparseCfrGpuKernels.ts`: Runtime class for sparse CFR compute pipelines.
- `treeBuffers.ts`: Sparse tree input and GPU buffer interfaces.
- `dispatch.ts`: Dispatch-limit and chunk-size helpers for sparse kernels.

### Subdirectories
- `shaders/`: WGSL source grouped by sparse CFR phase.
