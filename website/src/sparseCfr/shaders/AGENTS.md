## Directory summary
WGSL shader source for sparse public-tree CFR.

### Source files
- `core.ts`: Core sparse CFR kernels.
- `opponent.ts`: Opponent-policy and regret-weight kernels.
- `terminal.ts`: Showdown rank aggregation and terminal value kernels.
- `allIn.ts`: All-in table value kernels and optimized 1326-hand variants.
