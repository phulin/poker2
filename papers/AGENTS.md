## Directory summary
Plain-text model-context copies of poker and model research papers plus lightweight paper-processing notes.

## Source files
- `deepstack.txt`: Cleaned arXiv TeX source for DeepStack.
- `rebel.txt`: Cleaned arXiv TeX source for ReBeL.
- `supremus.txt`: Cleaned arXiv TeX source for Supremus/deep counterfactual value networks.
- `trm.txt`: Cleaned arXiv TeX source for Tiny Recursive Model.
- `alphaholdem.txt`: Extracted paper text for AlphaHoldem.
- `koikoi.txt`: Extracted paper text for Koi-Koi Hanafuda with Transformers.
- `requirements.txt`: Minimal dependency list for paper-processing utilities.
