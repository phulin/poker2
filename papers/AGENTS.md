# Papers Directory

This directory stores plain-text model-context copies of relevant research papers and lightweight dependency notes used while developing poker agents.

## Source files
- `deepstack.txt`: Cleaned arXiv TeX source for DeepStack.
- `rebel.txt`: Cleaned arXiv TeX source for ReBeL.
- `supremus.txt`: Cleaned arXiv TeX source for Supremus/deep counterfactual value networks.
- `trm.txt`: Cleaned arXiv TeX source for Tiny Recursive Model.
- `alphaholdem.txt`: Extracted paper text for AlphaHoldem; no matching arXiv TeX source was found during the current pass.
- `koikoi.txt`: Extracted paper text for Koi-Koi Hanafuda with Transformers; no matching arXiv TeX source was found during the current pass.
- `requirements.txt`: Minimal dependency list for paper-processing utilities.
