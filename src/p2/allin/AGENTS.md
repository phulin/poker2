## Directory summary
Preflop all-in equity modeling, random training-batch generation, Monte Carlo target estimation, and standalone training entry points.

### Source files
- `__init__.py`: Public package exports for the preflop all-in model, batch dataclass, random generator, and MC target sampler.
- `model.py`: Browser-friendly LeakyReLU/RMSNorm preflop all-in equity models with combo-moment, card-mass, rank/suit bucket, hand-conditioned blocker, optional dense-belief/output residuals, configurable low-rank FiLM branches, a native 169-class model with `[batch, 169, players]` input/output and exact class blocker features, native 169-class and 1326-combo player-token transformers with dtype-aligned scalar inputs and attention masks, and masked side-pot layer tokens to predict terminal values with optional folded-player key masking.
- `data.py`: Random terminal preflop all-in batch generation with per-player weighted-uniform stack sampling, configurable minimum live/all-in player counts, folded masks, all-in masks, one live covering caller, and selectable 1326-combo or native 169-class range dimensions.
- `precompute.py`: CLI and reusable API for building preflop all-in 169-class showdown tensors, including 2-player seat-0 `[169,169]` share collapse from combo tables, an optimized canonical 3-player seat-0 path with fp32 weighted sixth-share accumulation, suit-canonical full-board orbit weighting for exact runs, analytic exact 3p count denominators, resident CUDA board rank/mask tensors for exact canonical 3p, caller-order half-table symmetry with post-pass mirroring, grouped-board Triton accumulation to reduce atomics, CUDA-tuned class/tile chunks, uint16 quantized share artifact saving, and generic board-streamed 2/3-player class share/count tensors.
- `training_data.py`: Reusable online/offline all-in training-data generation, configurable minimum live/all-in player sampling, native 169-class online generation when requested, optional canonical board-rank cache use for all-boards pregeneration, optional online target workspace reuse, sharded dataset writing, manifest loading, optional 1326-to-169 pregenerated tensor collapse, pinned/async pregenerated shard reads, sequential/wrapped batch reads, and suit/player permutation remapping for beliefs, per-seat features, and targets.
- `sampler.py`: Preflop full-board Monte Carlo all-in value target estimator with tuple-reject opponent sampling, side-pot layer accounting, optional reusable CUDA workspaces, compact board-mask CUDA dispatch, canonical cached-board-rank exhaustive mode with orbit weighting, CPU reference fallback for 1326-combo target generation, and native 169-class target estimation without expanding compact beliefs to combo ranges.
- `kernels.py`: All-in-specialized Triton CDF tuple-reject sampler that scores by-hand side-pot payouts over sampled full-board rows, including compact board-mask accumulation, optional board orbit weighting, folded-hero skip paths, and native 169-class row-local CUDA scoring for compact all-in targets.
- `oracle.py`: Native 169-class preflop all-in oracle that loads quantized exact 2p/3p share caches, computes class-compatibility weighting for arbitrary compact beliefs, loads trained 4p-6p all-in models with CUDA BF16 compiled inference when enabled, and converts eligible-pot-share predictions to stack-normalized net values.
- `train.py`: Hydra-driven standalone training script with combo or native 169-class model modes, a separate Weights & Biases project, Muon or NorMuon/AdamW split optimization for linear matrices vs. scalar parameters, optional cosine/linear LR decay, stable warmdown, and cosine-then-linear-to-zero schedules, opt-in torch.compile support, checkpoint resume support, batch-size phase scheduling, online target workspace reuse, multi-epoch pregenerated train/validation data support with pinned CUDA prefetch, epoch-aware suit and player permutation augmentation, opt-in eligible-pot-share targets, and detailed throughput/loss/target/eval logging including validation MSE/MAE by live player count.
- `pregenerate.py`: CLI for pregenerating sharded 1326-combo or native 169-class all-in training datasets containing random features and `allin_values` targets with configurable minimum live/all-in player counts, including an exhaustive canonical-board-rank-cache target mode with fixed tuple samples per representative board.

### Subdirectories
There are no child source directories.
