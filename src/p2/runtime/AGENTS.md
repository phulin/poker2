## Directory summary
Shared runtime helpers for training entry points, including device setup, torch
runtime initialization, Weights & Biases lifecycle handling, and common run
metadata.

### Source files
- `__init__.py`: Package marker.
- `training_run.py`: ReBeL training runtime context manager, resolved-config artifact writer, W&B payload setup including non-resuming diagnostic runs, and model-summary helpers used by CLI orchestrators.

### Subdirectories
There are no child source directories.
