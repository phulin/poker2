## Directory summary
Reusable staged-training helpers for ReBeL workflows that are shared by CLI
entry points and scripts.

### Source files
- `__init__.py`: Package marker.
- `curriculum.py`: Staged postflop ReBeL curriculum implementation.
- `preflop_buckets.py`: Typed configuration boundary for preflop bucket stages.
- `preflop_backward_induction.py`: Preflop depth-bucket training and distillation implementation.

### Subdirectories
There are no child source directories.
