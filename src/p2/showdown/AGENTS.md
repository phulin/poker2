## Directory summary
Reusable multiway showdown equity evaluators and sampling kernels copied from benchmark prototypes.

### Source files
- `__init__.py`: Public package exports.
- `results.py`: Shared per-hand equity result helpers.
- `multiway_showdown_estimators.py`: Multiway showdown estimator implementations.
- `compare_multiway_showdown_tiers.py`: Tiered showdown evaluator comparison implementation.
- `exact.py`: Public exact-evaluator API.
- `approximate.py`: Public exports for aggregate and by-hand tier 1-4 approximate equity calculators.
- `monte_carlo.py`: Public Monte Carlo showdown evaluator exports.

### Subdirectories
There are no child source directories.
