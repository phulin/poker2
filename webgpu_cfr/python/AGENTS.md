## Directory summary
Python utilities used by the WebGPU CFR subproject to export PyTorch checkpoints and produce reference fixtures.

### Source files
- `export_model.py`: Exports a PyTorch BetterFFN checkpoint to `model.json` and `weights.bin`.
- `reference.py`: Builds Python CFR fixtures/results from a checkpoint and action-bin sequence for parity checks.

### Subdirectories
There are no child source directories.
